# 超能力者の証明 設計書(旧名 超能力者メーカー)

2026-11-19

## 1. どんなゲームか(意図)

なぜか**ごく普通の一般人の自分**が、地球上のすべての人に「超能力者だ」と信じさせなければならなくなった。デスゲーム調の理不尽な舞台で、伏せた4枚のカードから正しい図柄を**勘だけで**当て続ける。

遊びの芯は2つある。

- 当て続けるほど信者が増えていくドキドキ(連続で当たるほど乗数的に増える)
- リザルトで出る「あなたの最大連続回数は〇〇と同じくらいの確率です」という驚き

## 2. 目標・目標外・失敗の条件

**目標**
- スマホのブラウザで遊べ、GitHub Pagesで公開できる
- 世界人口は**全プレイヤー共通**で、世界中の挑戦者が消えるたびに減っていく
- 1回のめくりがテンポよく進む(目安は1回2〜3秒)。クリアまで平均で約130回かかるため
- 3Dのカメラワークでデスゲームの緊張感を出す
- 最後の1枚「運命の選択」が派手で記憶に残る

**目標外(今回はやらない)**
- ヒントや推理の要素。完全に運だけ
- オンラインのランキング(サーバーは「消えた挑戦者の数」の共有だけに使う)

**失敗の条件(動いても失敗とみなす)**
- 当たり外れに偏りや操作の余地がある(本当に1/4でないと、確率のリザルトが嘘になる)
- 1回ごとの演出が長く、130回を遊ぶのが苦痛になる
- 人の3Dがチープで、デスゲームの空気が壊れる
- スマホで重くて操作がもたつく

## 3. ルール(決定事項)

- 伏せたカードは4枚。図柄は4種類で、毎回1枚だけが「正解」
- 図柄はESPカード風の記号(○・＋・波・☆)【私の判断。ゼナーカードの5種から4つ】
- **部屋のモニターにマークが映り、4枚のうちそのマークのカードを1枚タップで当てる**(決定)
- 信者(信じてるゲージ)は**最初4人**
- **当たり**：信者×4、連続回数+1
- **外れ**：信者の**4分の1が離れる**(×3/4、端数切り捨て)。連続回数は0に戻る
- 信者が**0**になるか、**16回外したら**ゲームオーバー(2026-11-19 追加：中だるみ対策)
- 信者が**その時点の世界人口**以上になったらクリア(最初は82億人)
- **運命の選択**：当たれば信者が世界人口以上になる1枚で発動する(信者が世界人口の1/4以上のとき)。**一度きりで、当たればクリア、外せばゲームオーバー**(2026-11-19 変更)
- 正解の位置は毎回 `crypto.getRandomValues` で一様に決める

**参考(シミュレーション2万回)**：クリア率は約42%、クリアまでの中央値は約134回。ゲームオーバーは序盤(中央値4回)に集中する。信者が4〜5人のうちは2回外せば0になるため。

## 4. 画面と演出(3D、案A：全部3Dで決定)

技術は Three.js(WebGL)。スマホ縦画面を基本にする【私の判断】。

**舞台**
- 窓のない暗い部屋。真上からのスポットライトひとつ。中央のテーブルに4枚のカード
- プレイヤーは一人称視点。テーブルの手前に自分の手元が少し見える
- 周りの観客席に観客がいる

**観客の見た目**【私の判断】
- 人の3Dがチープにならないよう、**黒い仮面に赤く光る目をひとつ書き殴った、マネキンのような観客**にする(2026-11-19 変更)。ローポリで、表情は出さない。不気味さがデスゲームに合い、作りの粗さも味になる
- 動きは「一斉に首をかしげる」「立ち上がる」「背を向けて去る」など、体全体の簡単な動きで反応を見せる

**規模の変化**【私の判断】：信者の数で舞台が引いていく
| 信者の数 | 舞台 |
|---|---|
| 〜100人 | 小部屋の観客席 |
| 〜1万人 | 劇場(観客席が奥へ広がる) |
| 〜100万人 | 壁が倒れ、スタジアム級の群衆 |
| 〜1億人 | 夜の都市の明かりが観客 |
| 〜82億人 | 宇宙から見た地球。明かりが信者 |

観客は数の分だけ描かず、群衆はまとめて描く(インスタンス描画・光の点)。

**1回の流れ(2〜3秒)**
1. 正面のモニターにマークが映る
2. カードをタップ → カメラがそのカードに少し寄る → めくる
3. 当たり：観客がどよめいて立つ。信者の数がトゥルルと増える
4. 外れ：観客の一部が背を向けて去る。数字が減り、画面が一瞬赤くなる
5. すぐ次の4枚が配られる

**運命の選択**
- 照明が落ち、スポットライトが4枚だけを照らす。カメラがテーブルの周りをゆっくり回り込む
- 地球の全員が見守っている演出(地球の明かりが脈打つ)
- 選んだらスローモーションでめくる
  - 当たり → クリア演出：地球中の明かりがいっせいに灯る
  - 外れ → 通常どおり4分の1が離れる(ここで外す悔しさも見せ場)

**ゲームオーバー**(決定)：最後の1人が去り、暗転。そのあと文字で「その後、人口が一人減ったが誰も気づくことはなかった。」と出て終わる(2026-11-19 変更)。残酷な描写はしない

**世界人口が1人ずつ減る**(決定)：挑戦者がゲームオーバーになるたびに、世界人口が1人減る(消えた挑戦者のぶん)。暗転の後、人口カウンターが 8,200,000,000 → 8,199,999,999 と1つ減る演出を入れる。クリアに必要な人数も1人減る【減るのは「外れ1回ごと」ではなく「ゲームオーバー1回ごと」と解釈】

**世界人口は全プレイヤー共通**(決定)
- 小さなサーバーに「消えた挑戦者の数」を1つだけ置く。世界人口 = 82億 − 消えた挑戦者の数
- ゲーム開始時に数を取得し、ゲームオーバー時に1増やす
- いたずら対策【私の判断】：Firebaseの匿名ログインを使い、Firestoreのセキュリティルールで「1回の書き込みで+1だけ」「同じ利用者は前回から10秒以上あける(最短のゲームオーバーが約25秒のため)」を強制する(カウンターと利用者ごとの最終時刻を一括で書き込み、ルールで両方を検査)。App Checkも有効にする
- つながらないときは、最後に取得できた数(端末に保存)で表示し、ゲームは普通に遊べる
- リザルト画像に「あなたは〇人目の消えた挑戦者」を入れる【私の案】
- サービスは **Firebase(プレイヤーのアカウント)**。Firestore にカウンター文書を1つ置く。Cloud Functions は有料プランが要るため使わず、無料プラン(Spark)の範囲で作る【私の判断】

**スタート画面**(決定)：黒地の真ん中に白の縦書きで「超能力者の証明」。後ろで信者の赤い目がぼんやり光り、ときどきまばたく。画面をタップで進む(下に小さく「画面をタップ」と出すのは私の判断)。

**オープニングと次の挑戦者**(決定＋私の案)
- 初回：暗転から文字だけで「なぜか、あなたは全人類に超能力者だと信じさせなければならなくなった。」→ 部屋に照明が点く
- 2回目以降：「次の挑戦者は、こいつだ。」と出て、新しい挑戦者が紹介される【私の案：挑戦者番号・ありふれた名前・年齢・職業をランダムに組み合わせて表示。例「挑戦者 No.0042 佐藤 健一(38) 会社員」】。挑戦者番号はその端末で何人目か
- 主人公は毎回ちがう一般人。ゲームオーバー文の「彼」は挑戦者に合わせて「彼／彼女」を変える【私の判断】

**音**：BGMは**持ち主がドレミで書いた旋律(シ ミ レ♯ シ レ ド♯ ラ ド シ ソ ラ シ ラ ソ ミ ミ ファ♯ ソ ファ♯ ミ レ♯ ド♯ レ♯ ミ)をオルゴールにしたもの**(決定。115BPM、3音ずつ8分・8分・4分、4小節×2回の8小節ループ)。聴き心地は悪くないが少し不気味に：イ短調＋導音G#にそろえ、伴奏は小節ごとに旋律と半音でぶつかりにくい和音を選ぶ)。信者の段階ごとに楽器が増える(決定)：劇場で**バスドラ「ダン、ダダん」**(1つ目は必ずドラム)、スタジアムでベース、都市で暗い弦、地球で合唱【2つ目以降の楽器は私の判断】。、めくる音、どよめき、去る足音。運命の選択では心音

## 5. リザルト(決定事項＋私の案)

ゲームオーバーでもクリアでも出す。
- **最大連続回数**(決定)
- **その確率**：(1/4)^最大連続回数
- **「これは〇〇と同じくらいの確率です」**(決定)：段階ごとに身近なたとえを用意する【中身は作り手に任せる。例：2回=1/16「サイコロで…」、10回≈1/100万「宝くじ1等前後」】。数値は正確に計算し、たとえは近いものを選ぶ
- 最終的な信者数、めくった回数

最高記録(最大連続回数)は端末内(localStorage)に保存する【私の判断】。

**共有**(決定：リザルトを共有したい)【作り方は私の案】
- サーバーなしで、リザルトから**結果画像**を作って共有する。画像には挑戦者名、最大連続回数、確率とたとえ、最終信者数、ゲーム名とURLを入れる
- スマホは共有シート(Web Share API)で画像ごと送る。使えない環境では画像の保存と、文章＋リンクでのX投稿に切り替える
- リンクを貼ったときに画像が出るよう、OGP画像を用意する

## 6. 作り方の候補と選んだもの

- **A. 全部3D**(選択)：雰囲気は最高。人のチープさと作る量、スマホの負荷が課題 → 仮面のマネキン観客、群衆のまとめ描きで対処
- B. 全部2D：軽いが、カメラワークが出せずデスゲームの圧が弱い
- C. テーブルとカードは3D、人はモニター越しの2D：中間案

プレイヤーは、デスゲームの雰囲気には3Dがしっくりくるとして、Aを選んだ。

## 7. 作り手に任せること

- 3Dモデルの細部(部屋・カード・仮面)、色、ライティング
- 確率のたとえの文言と段階の刻み方
- BGMと効果音の素材選び
- スマホでの描画の軽量化
- 公開用リポジトリの名前(例：`nagashinocat/chounouryokusha-maker`)
